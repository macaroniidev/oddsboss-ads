Before you start

  • Website URL: use the OddsBoss link the owner sends you. Do not publish without it.
  • Conversion event: optimise for the sign-up or free-trial event the owner confirms in Events Manager.
  • Upload the ads exactly as they are. Do not add text, logos, stickers or music.

1. Campaign

  1. Create a new campaign. Objective: Sales. Campaign name: OddsBoss_US_Memes_Test1.
  2. Advantage campaign budget: OFF. The budget goes on each ad set (this is ABO).
  3. A/B test: OFF. Special ad categories: none.

2. Ad sets (make 2, settings are identical)

  1. Names: OB_US_ABO_Wins and OB_US_ABO_Losses.
  2. Conversion location: Website, with the event the owner confirms.
  3. Budget: $45 per day on each ad set. No end date.
  4. Advantage+ audience: OFF. Click "Switch to original audience options".
  5. Location: United States only (people living in or recently in). Age: 21 to 65+. Gender: all. Languages: English.
  6. Detailed targeting: leave empty (broad). If an "Advantage detailed targeting" box shows, untick it.
  7. Placements: Manual placements. Keep Facebook and Instagram Feeds, Stories and Reels. Untick Audience Network, Messenger, Threads, right column, search and in-stream video.

3. Ads (5 per ad set)

  1. Format: Single image. Upload the feed 4:5 file, then use "Edit placements" to put the stories 9:16 file on Stories and Reels.
  2. Paste the primary text, headline and call to action from each ad below. Use the ad name shown for each one.
  3. Advantage+ creative / creative enhancements: turn every option OFF. That includes visual touch-ups, text improvements, image brightness and contrast, image animation, adding overlays, image templates, expand image, 3D animation, enhance CTA, relevant comments, site links, translate text and product extensions.
  4. Music: OFF. Do not add any music.
  5. Multi-advertiser ads: OFF (untick).
  6. Website URL: the OddsBoss link from the owner. Add ?utm_source=meta&utm_campaign=memes_test1&utm_content= followed by the ad name, if the owner wants tracking.
