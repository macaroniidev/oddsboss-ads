OddsBoss: Round 2 campaign setup

How to set up the new campaign: two ad sets with the same 9 images and the same audience (men in the US, 21+), optimised for checkout starts. The only difference is the ad text: ad set A uses text A, ad set B uses text B. Meta's A/B test splits people between them, so the audiences don't overlap.

Download the 9 ads (.zip)

1 · Campaign

  1. New campaign. Objective Sales. Name OddsBoss_US_Memes_Test2.
  2. Advantage campaign budget OFF (each ad set gets its own budget). Special ad categories: none.

2 · Ad set A (text A)

  1. Name OB_US_R2_TextA. Budget $45 per day. Bid strategy Highest volume.
  2. Conversion location Website, pixel PV1 Ads Meta Pixel, conversion event Initiate checkout. Attribution 7-day click or 1-day view.
  3. Audience: click Switch to original audience options. Location United States (people living in or recently in). Age 21 to 65+. Gender Men. Detailed targeting empty, and if an Advantage detailed targeting box shows, untick it.
  4. Placements: Advantage+ placements.
  5. Schedule: leave the default, so it starts as soon as it's published.
  6. Add the 9 ads (step 4) with text A and the ad set A names and URL parameters. Publish, then do step 3 straight away.

3 · Ad set B (text B) and the A/B test

  1. In Ads Manager, tick ad set A and click A/B test. Choose to duplicate the ad set, and pick Creative as the variable.
  2. In the copy: name OB_US_R2_TextB. Budget $45 per day. Leave every other ad set setting exactly as in A.
  3. In each of the 9 copied ads: replace the primary text and headline with text B, rename the ad to its ad set B name and paste its ad set B URL parameters (they end in utm_term=text_b). Keep the same images.
  4. Test settings: key metric Cost per result (Initiate checkout). Start now, end date 14 days from today. If there's an option to end the test early when a winner is found, turn it off.
  5. Publish the test. Don't edit either ad set while the test runs: edits restart it.

4 · Ads

  1. Format Single image. Upload the feed 4:5 file, then "Edit placements" to put the stories 9:16 file on Stories and Reels.
  2. Call to action Learn More. Website URL https://getoddsboss.com/ on every ad.
  3. Advantage+ creative / creative enhancements: every option OFF. Music OFF. Multi-advertiser ads OFF.

Text A (Round 1 text): every ad in ad set A

Primary text
Stop throwing money at random parlays. OddsBoss researches, analyzes and gives you everything you need in seconds.
Headline
Tap to see why 10k+ users in the USA trust OddsBoss
