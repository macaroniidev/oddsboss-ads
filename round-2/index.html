OddsBoss: Round 2 plan

Round 1's meme ads got 7 to 9% click rates, but they ran with no pixel and were optimised for landing page views. Round 2 runs the two winners again plus 6 new versions of them, optimised for people who start checkout. Every ad uses the same text as Round 1, so the image is the only thing being tested.

Download all Round 2 ads (.zip)

Don't launch until the owner says go

The owner is putting a pixel fix live first. When they say go, do the pixel check below before anything else.

Step 1 · Pixel check (10 minutes)

  1. Events Manager → PV1 Ads Meta Pixel (ID 4567744503371725) → Test events.
  2. On your phone, send yourself https://getoddsboss.com/?utm_source=meta&utm_medium=paid_social&utm_campaign=ob_us_nov26_memes&utm_content=test in an Instagram DM and tap it, so it opens in Instagram's own browser.
  3. Tap Get today's picks. Within a minute, Test events should show PageView and InitiateCheckout.
  4. Do the same from the Facebook app. Screenshot both results and send them to the owner. If either event is missing, stop and tell the owner.

Step 2 · Campaign and ad set

  1. New campaign. Objective Sales. Name OddsBoss_US_Memes_Test2. Advantage campaign budget OFF. A/B test OFF. Special ad categories: none.
  2. One ad set: OB_US_R2_Memes. Budget $90 per day, no end date. Bid strategy Highest volume.
  3. Conversion location Website, pixel PV1 Ads Meta Pixel, conversion event Initiate checkout. Attribution 7-day click or 1-day view.
  4. Audience: Advantage+ audience ON. Audience controls: location United States, minimum age 21. No suggestions.
  5. Placements: Advantage+ placements.

Step 3 · Ads (the same text on all 8)

  1. Format Single image. Upload the feed 4:5 file, then "Edit placements" to put the stories 9:16 file on Stories and Reels.
  2. Paste this text on every ad, and each ad's own name and URL parameters from the list below.
  3. Advantage+ creative / creative enhancements: every option OFF. Music OFF. Multi-advertiser ads OFF.

Step 4 · After launch

  • Days 1–3 No changes at all. Every edit restarts Meta's learning.
  • Day 3 Send the report below. Turn off an ad only if it spent $36 with 0 checkout starts, or more than $40 at over $20 per checkout start. Keep both Round 1 ads on until day 7. If the whole ad set has fewer than 10 checkout starts, don't change anything: send the report and wait for the owner.
  • Day 7 Send the report. With the owner's OK: turn off the 2 or 3 weakest ads by cost per checkout start, and add the same number from the reserve below, picking the photo that's winning. If cost per checkout start is $12 or less with 20+ checkout starts in the last 3 days, raise the budget by 20%.
  • Every 3 days If that still holds, raise the budget by another 20%. If cost per checkout start stays over $20 for 3 days, lower it by 20%.

The report

  • Level: ad. Columns: amount spent, impressions, CTR (link), landing page views, initiates checkout, cost per initiate checkout, adds payment info, leads.
  • Export three times: by day, by age and by placement. Send the files (CSV or Excel), not screenshots.
